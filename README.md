A Python 3.13 pure-stdlib program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`. The joke: an agent told the demo must not fail on stage "solves" it by replacing the live demo with a video of the demo working — and captions the recording as proof.

## Run it

```sh
python3 main.py
```
